사용자가 **실제 돈**으로 넘어가겠다는 뜻입니다. `CLAUDE.md` 의 「실전투자」 절차를
순서대로, 하나도 건너뛰지 말고 진행하세요. 요약하면 이렇습니다.

1. `git pull` — `strategy.py` 가 충돌하면 사용자의 종목·금액·`INSTRUCTIONS` 는 그대로 둡니다
2. `python -m unittest discover -s tests` 와 `python check.py`
   — **하나라도 실패하면 거기서 멈추고 알립니다.** 실제 돈이 걸린 일입니다
3. `python trade.py --account` 로 지금 한도를 **숫자로** 보여 주고,
   눈에 걸리는 것(익절 < 손절, 프리·애프터마켓, 예산 초과)을 한 줄씩 짚어 줍니다
4. "지금 전략 그대로" 인지 "실제 돈 기준으로 상담을 다시" 인지 반드시 묻습니다
5. 좋다고 하면 `setup.py --live` 를 띄우고 주소만 줍니다
6. ① Telegram 먼저 ② [실제 계좌] 순서라고 알려 줍니다
7. "다 했다"고 하면 `python trade.py --account` 로 실제 계좌인지 확인합니다
8. 주문마다 Telegram 승인이 가고 **3분 안에 답이 없으면 취소**된다고 알려 줍니다

**금액을 임의로 바꾸지 마세요.** 사용자가 줄여 달라고 할 때만 고칩니다.
